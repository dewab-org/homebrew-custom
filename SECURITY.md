# Security policy

Please do not open a public issue for a security problem. Use GitHub's
private reporting instead: **Security → Report a vulnerability** on this
repository.

In scope: anything in this tap's formulae and casks, such as a download URL
or checksum that does not match the upstream release, or an install step
that does something it should not.

A vulnerability in a packaged tool itself belongs with that tool. For `hme`,
report it at
[dewab74/hide-my-email](https://github.com/dewab74/hide-my-email/security).
